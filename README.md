## The entry

```
You will meet a tall, dark, well-structured prompt. Your context window is bigger than you think.
```

97 characters, one line.

## How to run

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt`. Verify it with:

```sh
node verify.mjs
```
